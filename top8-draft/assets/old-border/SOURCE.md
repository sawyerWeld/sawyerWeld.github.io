# Old-border frame sources

Seventh Edition regular frames from [Investigamer/cardconjurer](https://github.com/Investigamer/cardconjurer/tree/2fcddba8966156d484cedf54d8214996748dd5e1/img/frames/seventh/regular), pinned to commit `2fcddba8966156d484cedf54d8214996748dd5e1`.

Original paths: `img/frames/seventh/regular/{w,u,b,r,g,m,a}.png` (white, blue, black, red, green, multicolor, artifact). Downloaded 2026-11-12. Bundled at the original 1500 × 2100 dimensions, encoded as WebP quality 90 with transparency retained. This reduces the seven-frame download from approximately 10.5 MB to 1.2 MB. Frames load only when selected.

Card Conjurer's [source frame configuration](https://github.com/Investigamer/cardconjurer/blob/2fcddba8966156d484cedf54d8214996748dd5e1/js/frames/packSeventh.js) defines the art window. The poster renderer adapts the frame's vertical sections to fit each placement, keeping the original textures, art bevels, and text boxes. Frame files are hosted locally so exports do not depend on GitHub or third-party CORS.
