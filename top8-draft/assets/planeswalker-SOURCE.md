# Planeswalker symbol

The canvas watermark uses the unmodified path from [Mana’s planeswalker.svg](https://github.com/andrewgioia/mana/blob/6ca9e696d3bda2519dcf3eebd96598f84ad9ddd8/svg/planeswalker.svg), by Andrew Gioia, pinned to commit `6ca9e696d3bda2519dcf3eebd96598f84ad9ddd8`. It is embedded as a Canvas Path2D and scaled/recolored for the background.
